# تحدّي النظافة 🏆 — مسابقة صفّية على الشاشة

لعبة مسابقة بأسلوب Kahoot، بتنعرض على شاشة الصف أو البروجكتور.
فريقين، وممثل من كل فريق بيجاوب بالتناوب. **بدون تلفونات وبدون تسجيل** — بس الشاشة والمعلّمة.

**ملف واحد ستاتيك:** `index.html` — ما في بناء ولا تبعيّات.

## كيف بتشتغل

1. المعلّمة بتكتب أسماء الفريقين وبتختار إيموجي لكل فريق.
2. بتختار عدد الأسئلة (6 / 10 / 14 / الكل) ووقت السؤال (15 / 25 / 40 ثانية).
3. كل سؤال إله دور: ممثل الفريق بيجاوب، والمعلّمة بتضغط الجواب اللي حكاه.
4. **فرصة السرقة** (اختيارية): إذا الفريق غلط أو خلص وقته، الفريق التاني بياخد فرصة بنص النقاط.
5. بآخر الجولة بتظهر شاشة الفائز مع النقاط.

النقاط: 500 نقطة أساس + لحد 500 حسب سرعة الجواب. السرقة بنص النقاط.

## اختصارات الكيبورد (للمعلّمة)

| المفتاح | الوظيفة |
|--------|---------|
| `1` `2` `3` `4` | اختيار الجواب |
| `مسافة` / `Enter` | السؤال الجاي |
| `F` | ملء الشاشة |
| `M` | كتم الصوت |

## تعديل الأسئلة

كل الأسئلة بمصفوفة `BANK` جوّا `index.html`. كل سؤال سطر واحد:

```js
["نص السؤال؟", ["جواب 1","جواب 2","جواب 3","جواب 4"], 0]
//                                                      ↑ رقم الجواب الصح (بيبدأ من 0)
```

زيد أسئلة قدّ ما بدك — اللعبة بتخلط الأسئلة وبتاخد العدد اللي انتخب.
