# مغامرة «مِحفَظة الذهب» — لعبة تفاعلية

**إعداد الطالبة: جنى رامي أسعد بشير**

لعبة أسئلة تفاعلية مبنية على قصة «مِحفَظة الذهب». افتح الملف `index.html` في أي متصفح (لا يحتاج إنترنت إلا للخطوط).

## مسار اللعبة
1. **شاشة البداية** ← كتابة اسم اللاعب.
2. **خريطة تحدي الأبطال** — ست محطات:
   - محطة الكتاب: لغز الغلاف (اختيار من متعدد)
   - أبطال الحكاية: اسحب الصفة إلى صاحبها (سحب وإفلات)
   - أين ومتى؟ سر الوقت (صباح / ليل)
   - قطار الأحداث: ترتيب الصور (البداية، الوسط، النهاية)
   - عدسة المحقق: السبب والنتيجة
   - شجرة الحكمة: العبرة من القصة
3. **بئر الأسرار** يُفتح بعد إنهاء المحطات ← ثلاثة تحديات: مَن القائل؟ / اكتشف المعنى / رأيك يهمنا (سؤال مفتوح مع إجابة مقترحة).
4. **شهادة البطولة**: الاسم، القطع الذهبية، النجوم.

النقاط: 10 قطع للإجابة من المحاولة الأولى، 6 للثانية، 3 بعدها.

## التعديل
المصدر في `game-src/`. بعد تعديل `game.src.html` أعد البناء:

```bash
python3 game-src/build.py game-src/game.src.html game-src/assets index.html
```
