# يوم النظافة العالمي — موقع فعالية صفّية 🌍

موقع تفاعلي جاهز للنشر، مبني لفعالية **اليوم العالمي للنظافة** (السبت الثالث من أيلول) لصف مدرسي.
كل الصفحة بالعربية ومن اليمين لليسار، وبتشتغل على الموبايل والشاشة الكبيرة، وفيها وضع ليلي.

## شو في بالموقع

| القسم | الوصف |
|------|-------|
| الواجهة | عنوان + عدّاد تنازلي لموعد الفعالية |
| عن اليوم | تعريف باليوم العالمي وأرقام بتتحرّك |
| برنامج اليوم | جدول سبع محطات من الصباح للتكريم |
| المسابقة | نظام النقاط + لوحة نقاط للفرق (بوضع تعديل للمعلّمة) |
| بطاقة المهمات | 10 مهمات مع شريط تقدّم، بتنحفظ تلقائيًا |
| الكويز | 7 أسئلة مع تصحيح فوري وشرح |
| لعبة الفرز | 10 أغراض بتنفرز على 4 حاويات |
| التعهّد | زر تعهّد مع عدّاد |
| السلامة | 6 قوانين للطلاب |
| الشهادة | اسم الطالب → شهادة مشاركة قابلة للطباعة أو الحفظ PDF |

كل التفاعل بينحفظ محليًا على الجهاز (`localStorage`) — ما في سيرفر ولا قاعدة بيانات.

## التعديل

كل الإعدادات بأول ملف `app.js` تحت `CONFIG`:

```js
const CONFIG = {
  className: "صف جنى",              // اسم الصف
  schoolName: "",                    // اسم المدرسة (اختياري)
  eventDate: "2026-09-19T08:00:00",  // موعد الفعالية للعدّاد
  dateLabel: "١٩ أيلول",             // التاريخ زي ما بيظهر بالشهادة
  teams: [ /* أسماء الفرق وإيموجي كل فريق */ ]
};
```

باقي المحتوى (برنامج اليوم، المهمات، أسئلة الكويز، أغراض اللعبة، قوانين السلامة)
موجود كمصفوفات واضحة بنفس الملف: `PLAN`, `MISSIONS`, `QUIZ`, `ITEMS`, `SAFETY`.

## التشغيل محليًا

ملفات ستاتيك بس — افتح `index.html` مباشرة، أو:

```bash
npx serve .
```

## النشر على Vercel

1. افتح [vercel.com/new](https://vercel.com/new) واختر هذا المستودع.
2. Framework Preset: **Other** — بدون أمر بناء وبدون مجلد إخراج.
3. Deploy.

أو من التيرمنال:

```bash
npx vercel --prod
```

## الملفات

```
index.html    الصفحة
styles.css    التصميم (متغيّرات ألوان + وضع ليلي + تنسيق طباعة الشهادة)
app.js        الإعدادات والمحتوى وكل التفاعل
vercel.json   إعدادات النشر
```
